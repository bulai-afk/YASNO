# Эталон оформления YASNO — исходник SVODKA

## Коррекция после замечания пользователя

Предыдущий новый макет отклонён: он изменял исходный дизайн. Он не является утверждённым направлением.

`01-report-configuration.html` теперь содержит исходный `public/stitch/svodka_1/code.html` из пользовательского архива без изменений. Это визуальный эталон, не реализованный генератор. В нём остаются старые демонстрационные данные и обработчики, обнаруженные при аудите.

В приложении этот HTML открывается с `?shell=1` внутри исходных `AppShell`, `AppSidebar` и `AppTopbar`. Файлы этой оболочки сохранены рядом в `original-shell/` как справочный исходник. Самостоятельное открытие HTML может показывать его встроенную оболочку; точный предпросмотр получен запуском исходного React-приложения.

## Обязательные ограничения

- Не перерисовывать интерфейс «по мотивам».
- Сохранять исходные DOM-структуру, CSS-классы, цвета, градиенты, шрифты, плотность, отступы и размеры карточек.
- Не заменять боковую и верхнюю панели новым дизайном.
- Исправлять обработчики, состояние формы, источники данных и серверные операции в существующей вёрстке.
- Любой необходимый визуальный diff (включая адаптивность и новые состояния) сначала показывать пользователю и согласовывать.
- До согласования не внедрять другой вариант экрана.

## Следующие функциональные исправления без редизайна

1. Один обработчик запуска, без конфликта двух переходов.
2. Сохранение шаблона отдельно от запуска.
3. Передача выбранного сайта, периода, целей и разделов в серверное задание.
4. Корректные состояния недоступных источников — текст и оформление согласовать отдельно.
5. Единый сохранённый результат для WEB и PDF.

## Ранее согласовано

Локальный запуск, email-код, несколько основных целей с дедупликацией по визиту, ручное формирование, WEB+PDF, только анализ/задачи/экспорт. Метрика и Вебмастер доступны; production API Директа пока нет.

Секреты, `.env.local` и клиентские выгрузки не публикуются. Рабочий фронтенд main не изменялся.
