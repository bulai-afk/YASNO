# Согласование экранов YASNO

Рабочие экраны изменяются только после подтверждения пользователя.

## 01. Преднастройка отчёта — ожидает согласования

Открыть `01-report-configuration.html` в браузере. Файл автономный, без внешних запросов.

Сохранена структура исходного макета: сайт, сценарий, период, источники/цели, глубина анализа, боковая сводка. Два переключаемых режима: полный и экспресс.

Предложенные уточнения: несколько основных целей с дедупликацией по визиту; база сравнения; явное отсутствие production API Директа; WEB и PDF из одного результата; раздельные действия генерации и сохранения шаблона.

Все данные вымышлены. Это макет согласования, а не реализация серверных функций. Граничный период 93 дня и набор разделов — предложения, не утверждённые требования.

Проверено локально: 1440 и 390 px, переключение режима/периода/сайта, запрет запуска без целей, окна запуска и шаблона.

Далее на согласование: генерация; полный/экспресс-отчёт; PDF; задачи; вход и подключения.

## Уже согласованные требования

- Запуск сначала на компьютере пользователя.
- Email-код; реальную отправку SMTP нужно отдельно настроить.
- Метрика и Вебмастер — реальные интеграции; Директ пока без production API.
- Только ручное формирование отчётов.
- Только анализ, задачи и экспорт, без изменения рекламных кампаний.
- Токены, `.env.local` и исходные клиентские выгрузки не публикуются.
