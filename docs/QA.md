# Проверка прототипа v0.1

## Автоматические проверки

- 4 проверки структуры/синтаксиса: успешно.
- 51 браузерная проверка Playwright: успешно, включая проверки отсутствия горизонтального переполнения страницы на снимках.
- Ошибки JavaScript во время тестового прогона: 0.
- Внешние HTTP(S)-запросы во время тестового прогона: 0.

Браузерные сценарии: семь разделов, периоды, вход с верным и неверным демо-кодом, отключение/включение Метрики, пустой отчёт, фильтр приоритета, добавление задач, смена и сохранение статуса, экспорт, проверка домена и дубликата, новый проект, демо-аудит, мобильное меню, закрытие диалога Escape, подтверждённый сброс.

## Визуальная проверка

Проверены desktop 1440 px и mobile 390 px: разделы, вход/код/ошибка, источники, детализация ошибки, добавление проекта, запуск демо-аудита, план без задач и с задачей, мобильное меню и диалоги, включая прокрутку длинных диалогов до кнопок.

Исправлено при проверке: размеры и цвет иконки в CTA пустых состояний, размещение краткой таблицы на телефоне, подсказка прокрутки полной таблицы и устаревшие уведомления при переходе между разделами.

Полная таблица трафика на телефоне намеренно прокручивается по горизонтали внутри собственного контейнера, а не всей страницы. Краткая таблица обзора помещается целиком. Длинные диалоги прокручиваются внутри окна.

Для основных пар текст/фон рассчитан контраст; есть подписи полей, видимый фокус, native dialog и текстовые обозначения приоритетов. Это не полноценная сертификация WCAG и не тестирование всех браузеров и ассистивных технологий.

## Не проверялось — потому что не реализовано

Доставка писем, защита реальных сессий, OAuth, доступы к API, живые кабинеты, серверная изоляция пользователей, сетевой обход сайтов, нагрузка и размещение. Этот прогон нельзя считать приёмкой production SaaS.
